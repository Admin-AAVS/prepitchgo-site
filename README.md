# prepitchgo.app

Teaser site for Pre-Pitch GO!, hosted on GitHub Pages at https://prepitchgo.app.

Single static page (`index.html`) plus images and two looping soundtrack MP3s.
No build step. Push to `main` to deploy.

Assets come from the marketing image package and the final release soundtrack
(Main Menu "PrePitchGo Anthem" and Trophy Shelf "Spree"), encoded for web.
